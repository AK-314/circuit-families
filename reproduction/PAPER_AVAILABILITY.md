# Paper availability statement

Use the following text in the final paper PDF:

> **Code and data availability.** Code, data, selected model checkpoints, recorded analysis
> outputs, and reproduction instructions accompanying this paper are archived at
> <https://doi.org/10.5281/zenodo.21917638>. The development repository is available at
> <https://github.com/AK-314/circuit-families>.

If the venue permits artifact citations in the bibliography, use:

> Kolesnikov, A. (2026). *Grokking Opens a Family of Sparse Circuits: Code, Data, and
> Reproducibility Artifact* (Version 1.0.0) [Software and dataset]. Zenodo.
> <https://doi.org/10.5281/zenodo.21917638>

The archived DOI is the canonical reproducibility reference. The GitHub repository is the
readable development location and should link back to both the archived artifact and the paper.
