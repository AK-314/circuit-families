# Circuit Families

Research code for studying how recoverable sparse circuit families change across the
grokking transition in a modular-addition transformer.

## Authoritative documents

* `experimental_protocol.md`
* `implementation_order.md`

## Environment

* Python 3.11
* PyTorch
* TransformerLens
* uv dependency management

Install the locked environment:

```bash
uv sync
```

Run tests:

```bash
uv run pytest
```

Run lint checks:

```bash
uv run ruff check .
```

## Project rule

Scientific results must be generated by scripts from saved configurations and must trace to model, dataset, checkpoint, circuit and Git manifests.
